# 📋 Task Manager

A simple **Task Manager** web application built with **Node.js**, **Express**, and **EJS**, using the **filesystem (fs)** module for storing task data. This project includes a fully functional backend and dynamic frontend.

## 🚀 Features

- 📝 Create and manage tasks
- ✅ Mark tasks as complete
- 🗑️ Delete tasks
- 💾 Stores data in local JSON/text files
- 🖥️ Built with Express and EJS templating

## 🔧 Tech Stack

- Node.js
- Express.js
- EJS (Embedded JavaScript templates)
- File system module (fs)
